## 🧰 Shared Skills

Public [Claude Code skills](https://docs.claude.com/en/docs/claude-code/skills) and tools in this repo. Copy a skill folder into `~/.claude/skills/` (or a project's `.claude/skills/`) to use it.

| Skill | What it does |
| --- | --- |
| [car-hunt](skills/car-hunt/SKILL.md) | Finds, researches, and ranks used Honda/Toyota vehicles by cost per remaining mile, with VIN recall and total-cost-of-ownership lookups. Includes an insurance-claim comp mode that finds high-priced dealer comps for a totalled vehicle. |
| [drive-ocr](skills/drive-ocr/README.md) | Finds Google Drive PDFs without a text layer, OCRs them with `ocrmypdf`, and replaces them in place — keeping file IDs, names, sharing, and folders. |
| [onenote-migration](skills/onenote-migration/README.md) | Migrates a personal Microsoft OneNote account to a Git repo of Markdown files via Microsoft Graph, keeping hierarchy, attachments, and version history. *(Standalone Python tool, no `SKILL.md`.)* |
| [packaging-scout](skills/packaging-scout/SKILL.md) | Researches and scores packaging options (boxes, mailers, jars, labels, void fill) for a product, then delivers a ranked recommendation, sourcing list, and PDF report. |
